All the case options are made for PandaKB's Corne V3 MX kit. I assume other V3 cornes use the same pcb layout, but i have no way of actually knowing this so do your own research.

Since i never can land on just one thing, i've made few versions of the same case. First one is very basic, lower version. 2nd one has raised edges that sit flush with mx keycaps, 3rd option uses tenting legs you can source from AliExpress.
